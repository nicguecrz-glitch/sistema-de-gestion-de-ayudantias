# Sistema de Gestión de Ayudantías

## Descripción del proyecto

El Sistema de Gestión de Ayudantías es una propuesta de aplicación web desarrollada como parte de la materia Ingeniería de Software I de la ESPOL. Surge de la necesidad de centralizar la información de las ayudantías y facilitar el seguimiento de la asistencia estudiantil.

El objetivo del proyecto es facilitar el registro de las sesiones de ayudantía y de la asistencia de los estudiantes, así como la consulta de reportes por materia, paralelo y período académico.


## Alcance y roles

El Sistema de Gestión de Ayudantías contempla el registro de sesiones, el control de la asistencia estudiantil y la consulta de reportes por materia, paralelo y período académico.

| Rol | Participación en el sistema |
| --- | --- |
| Estudiante | Registra su asistencia a las sesiones de ayudantía. |
| Ayudante | Registra las sesiones que imparte y revisa la asistencia de los estudiantes. |
| Profesor | Consulta la información de las ayudantías y la asistencia de sus paralelos. |
| Administrador | Consulta la información de las ayudantías dentro del ámbito que tiene asignado. |
| Súper administrador | Asigna administradores y define las materias y los períodos académicos a los que tendrán acceso. |
